# ハーネスの ADR

ハーネス(進め方、skill、検査、タスク)の判断を残す。プロジェクトの技術選定や構成の判断は、プロジェクトの ADR(`docs/adr/`)に書く。
ハーネスを持ち出した先のプロジェクトの ADR が ADR-0001(そのプロジェクトの技術選定など)から始まるように、番号を分けている。ハーネスの ADR は zip に入れず、配る skill や文書からも参照しない([HADR-0008](0008-harness-boundary.md))。

- 置き場所と番号: `docs/harness/adr/NNNN-<英語の短い名前>.md`、題名は「HADR-NNNN: <決めたことを 1 文で>」。`HADR` は Harness ADR の略。
- 書き方と運用ルール(状態、マージ後に書き換えてよい範囲、書くこと・書かないこと)は、プロジェクトの ADR と同じ [ADR の運用ルール](../../adr/README.md) に従う。テンプレートも同じ([テンプレート](../../templates/adr.md)。題名の `ADR-` を `HADR-` にする)。
- ハーネスの判断を変えるときは、このリポジトリで新しい HADR を足す。
